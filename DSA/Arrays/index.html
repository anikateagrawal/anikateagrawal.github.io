Frequently Asked Interview Problems

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

Optimized Solution (O(n) Time, Hash Map):
function twoSum(nums, target) {
  const map = new Map();
  for (let i = 0; i < nums.length; i++) {
    const diff = target - nums[i];
    if (map.has(diff)) return [map.get(diff), i];
    map.set(nums[i], i);
  }
}

Find the contiguous subarray with the largest sum and return its value.

function maxSubArray(nums) {
  let maxSoFar = nums[0], currentMax = nums[0];
  for (let i = 1; i < nums.length; i++) {
    currentMax = Math.max(nums[i], currentMax + nums[i]);
    maxSoFar = Math.max(maxSoFar, currentMax);
  }
  return maxSoFar;
}

Array Complexity Quick Reference

  • Access by index: O(1) constant time complexity.
  • Linear Search: O(n) worst-case time complexity.
  • Insertion / Deletion: O(n) because elements must shift positions.
