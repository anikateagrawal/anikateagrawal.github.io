SQL Joins & Subqueries

Combine rows from two or more tables based on related columns and execute nested queries.

Common SQL Join Problems

INNER JOIN: Returns only matching records from both tables.
LEFT JOIN: Returns all records from left table and matching records from right table (with NULLs for non-matches).

-- Example Query
SELECT e.emp_name, d.dept_name
FROM Employees e
LEFT JOIN Departments d ON e.dept_id = d.id;

SQL Join Types Cheat Sheet

Memory shortcut: Visualizing Venn diagrams helps determine whether an Inner, Left, Right, or Full Outer Join is required.
